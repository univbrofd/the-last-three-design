# HANDOFF — OnboardingChatView（ビデオ通話化）

repo: `univbrofd/the-last-three-design` / branch `main`
raw base: `https://raw.githubusercontent.com/univbrofd/the-last-three-design/main/`
DS 索引: `DesignSystem/_ds_manifest.json` / 土台: `DesignSystem/USAGE_RULES.md` → `taste.md`

## タスク

登録ヒアリング画面を **チャット UI → ビデオ通話 UI** に作り替える。
既存デザイン（チャットバブル版）= `handoff/AppPrototype/OnboardingChatView.dc.html`。これを Before として Before/After を示すこと。

体験の狙い: **「面接を受けている」感覚**。ユーザーは自分が見られている側で、相手（AI）は画面いっぱいに映り、目を合わせて質問してくる。5 分間、逃げ場がなく、しかし責められてはいない。

## 要件（必須）

1. **チャットバブルを全廃**。吹き出し・左右振り分け・スクロールする会話ログを持たない
2. **ビデオ通話の画面構成** — 相手（AI）が full-bleed で大きく映る。自分はインカメラの小窓（PinP）
3. **AI の発話は字幕**（キャプション）。1 文字ずつ送る演出前提なので、送り途中／送り完了の 2 状態が要る
4. **音声が既定、テキストでも答えられる**。キーボードに切り替えると入力欄がせり上がる。選択肢チップも残す
5. **進行が分かる** — 通話時間と `Q n / N`。ヒアリング中であることが常に読める

## 相手（AI）の見え方 — 方向は確定済み

**粒子・ノイズで結ばれた人型の像**（実写でもイラストでもない）。AI であることを隠さない誠実な表現で、既存の「退色・粒子」モチーフと同じ語彙で作る。

- 参照する体験は「ゲーム冒頭で博士が語りかけてくる」型（全画面・語り・文字送り・選択）。**既存キャラクターの見た目は複製しない**
- 人型と分かる密度分布を持つ（肩・首・頭部のシルエットが読める）。顔の造作は描き切らず、**目のあたりだけ密度が上がる**ことで視線を成立させる
- `--primary` は像の装飾に使わない（`USAGE_RULES §3`）。像は `--text-1/2/3` 相当の明度差と粒子密度だけで作り、灯りは進捗・CTA・選択状態にのみ点く
- **弱点の補強（重要）**: この表現は面接官としての「生々しさ・視線の圧」が出にくい。次で補う設計を示すこと
  - 発話中／傾聴中で**粒子の密度と収束度が変わる**（話すとき収束して輪郭が締まり、待つときはわずかに拡散して揺らぐ）
  - ユーザーが黙っている間も像は動き続ける（呼吸 4s ease-in-out・微細なノイズの流れ）。静止させない
  - 山場の質問では像が一段近づく／収束が最も強くなる
- 口の動き・まばたき・呼吸をどのパラメータで作るかを分解して示す（例: 口 = 特定領域の密度 0→1、まばたき = 目領域の一瞬の消失）。Flutter 実装では音声振幅で駆動する前提

## 成果物

`.phone` 枠（402×874）に full-bleed で実配置した specimen を、シーンごと 1 ファイル:

| # | 状態 | 内容 |
|---|---|---|
| 1 | 入場 | 暗転から像がフェードイン。接続中→開始 |
| 2 | AI 発話中 | 字幕がタイプ中・口が動く・波形 |
| 3 | 応答待ち | マイク待受、入力レベル、無音の間 |
| 4 | 選択肢提示 | チップが字幕の上に出る |
| 5 | テキスト入力 | キーボード想定で入力欄がせり上がる |
| 6 | 山場 | 「許せないことを、ひとつだけ」の演出（現行 highlight カード相当） |
| 7 | 完了 | 「待機をはじめる」CTA |

各 specimen 先頭に `@dsCard`、`_ds_manifest.json` に登録。最終は bundle で出力。

## 配置文脈（必須）

- 402×874・画面角丸 55・SafeArea 上 62（Dynamic Island 含む）/ 下 34 = `DesignSystem/preview/card.css` の `.phone`
- タップ範囲 最小 44×44pt（見た目 20px でも当たり判定 44）
- 像の上に置く文字・アイコンは `--scrim-min`（rgba(0,0,0,.45)）以上のスクリムの上に

## 実装由来の設計値（現行実装から捕捉・値で固定）

参考: 別 repo（本体アプリ）の `lib/feature/OnboardingChat/`。以下は実測値。

**背景**: 上端 300px に radial-gradient（中心 50% 0%・半径 1.2・`--primary` 10% → 0%・stop 0/0.62）

**進行ヘッダ**: padding 8/24/14/24・行間 10
- 左 `COUNSELING · 5 MIN`（mono 10px / letter-spacing .16em / `--text-3`）
- 右 `Q3 / 5`（同 mono・`--primary`）
- バー: 高さ 2px。地 `--border`、進捗 `--primary`、幅変化 500ms ease

**AI 発話**: ラベル `AI`（mono 9.5px `--text-3`）+ 本文 16px / line-height 1.75 / `--text-1`
**ユーザー発話**（廃止対象）: `--surface-raised` / radius 18 18 4 18 / padding 16×12 / 15px 1.6 / 最大幅 74%
**山場カード**: `--surface` / radius 20 / border `rgba(233,178,106,.34)` / padding 20 20 22
- 呼吸ドット 5px `--primary`（4s ease-in-out）+ `THE ONE THAT MATTERS`（mono 10px `--primary`）
- 見出し: Instrument Serif 26px / 1.35 / `--text-1`
- 補足: 13.5px / 1.7 / `--text-2`

**選択肢チップ**: 高さ 44 / radius 22 / `--surface` / 1px `--border` / 14px `--text-2`
- 選択時: 背景 `rgba(233,178,106,.16)` / border `--primary` / 文字 `--primary`
- 折り返し gap 8

**入力欄**: 高さ 52 / radius 26 / `--surface-raised` / 1px `--border` / 左 padding 20
- placeholder `話す、または打つ`（15px `--text-3`）
- 送信ボタン: 52×52 円 `--primary`、中に 11×19 radius 6 の `--on-primary`

**CTA**: 高さ 52 / 全幅 / radius 26 / `--primary` / 15px w700 `--on-primary` / ラベル `待機をはじめる`

**コピー実値**（字幕に流す実文）
- `はじめに、なんと呼べばいいですか。`
- `生まれた日を教えてください。年齢は相手に見えますが、日付は見えません。`
- `いま、どのあたりに住んでいますか。`
- `体つきは、どれに近いですか。`
- `顔写真を 1 枚だけ。あとからでも変えられます。`
- 山場: `許せないことを、ひとつだけ教えてください。` / 補足 `好きなものより、これが合うかどうかで決まります。答えは誰にも公開されません。`
- 締め: `登録は以上です。ここから先は、AI が探します。届いたときが、はじまりです。`
- 選択肢例: `嘘をつく人` / `時間にルーズ` / `店員への態度`

**状態**: 発話中 / 応答待ち / 送信中（3 点の呼吸ドット）/ 写真アップロード中 / エラー（`画像を保存できませんでした。もう一度お試しください。`）/ 完了

## 直すべき逸脱

- 通話 UI の定番（赤い REC 点・緑の応答ボタン・赤い終了ボタン）は `USAGE_RULES §6` で禁止。録音中は `--primary` の呼吸ドットか `--text-3` の mono ラベルで表す
- **通話終了ボタンを置かない**（ヒアリングから離脱させる導線を作らない）。ミュートとキーボード切替のみ
- 現行実装に `rgba(245,241,234,.86)` 相当の素の透明度直書きが残る → `--text-1/2/3` の役割トークンに寄せる
- `--primary` は「灯り」用途のみ（進捗・主要 CTA・選択状態）。装飾・区切り線・アイコン全般には使わない
- エフェクト予算 1 コンポーネント 1〜2 個（像 = スクリム + 退色のみ、そこにグローを足さない）
