# HANDOFF — AppPrototype（デザイン初稿）

タスク: 「the last three」のブランド確定＋コア 5 画面のデザイン初稿。
状態: design repo は未 push のローカル seed（raw リンク運用は初稿確定後）。本ハンドオフはプロンプト貼り付け＋参照画像添付で Claude Design へ渡す。取り込みは `import-design-bundle`（DS foundation は DesignSystem/ へ、画面 specimen は handoff/{View}/ へ再配置）。

## アプリコンセプト

- 同時マッチング上限 **3 人**。無限スワイプを廃し「誰と向き合い、誰を手放すか」のリソース管理と埋没費用（サンクコスト）で中毒性を作るマッチングアプリ
- 登録 = プロフィールフォーム廃止。AI チャット対話 5 分（経験・人生設計・趣味・「嫌いなこと / 許せないこと」）
- 待機 = 自分で探す機能なし。AI が相手を見つけると push 通知（宝箱を開ける特別感・「選ばれた 3 枠」）
- 日常共有 = 運営お題（例: 平日の昼ごはん / 最近一番の買い物）に沿って写真投稿。AI が裏で写真分析しマッチ精度へ還元
- 絆ゲージ = 無反応で関係が自動解除（マッチ直後 0–3 日: 24h / 1 週間〜: 72h / 1 ヶ月〜: 1 週間）。長く続くほど切れにくい
- 別れ = 自分から振る側・放置で切らせた側だけ重い待機時間ペナルティ（非対称・囚人のジレンマ）。振られた側は即座に枠解放
- 終焉演出 = 解除が近づくとふたりのタイムラインの思い出写真が徐々に色褪せる（モノクロ化・ノイズ）＋カウントダウン

## 画面（specimen 対象・各 1 ファイル・`.phone` 402×874 に実配置）

1. **OnboardingChatView** — AI チャット登録。カウンセリング風の没入 UI。「嫌いなこと」を引き出す演出
2. **WaitingView** — 待機ホーム。探す UI なし。「AI が探している」静かな状態＋マッチ通知が届く瞬間（宝箱開封の特別感）
3. **MainView** — メイン。横長写真カードが縦に 3 枠（参照: `shots/main-ui-reference.png`）。各枠 = 相手の最新お題写真 full-bleed＋名前バッジ（左上・アバター）＋いいね / リプライ。空き枠・クールダウン中の枠の状態も併記
4. **PairTimelineView** — ふたりだけのクローズドタイムライン。お互いのお題写真が時系列、お題バナー、写真への いいね / リプライ → チャットへ自然遷移
5. **BreakupView** — 解除接近状態。絆ゲージ・カウントダウン・写真の退色（モノクロ / ノイズ）。PairTimelineView の状態バリアントでも可
