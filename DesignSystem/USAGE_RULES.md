# USAGE_RULES.md — the last three

## 1. トークン
値の直書き禁止。`colors_and_type.css` の役割トークンのみを参照する。

| トークン | 値 | 用途 |
|---|---|---|
| `--bg` | `#0B0A0C` | 画面地 |
| `--surface` | `#151318` | カード・シート |
| `--surface-raised` | `#1E1B22` | 入力欄・チップ |
| `--border` | `rgba(255,255,255,.10)` | 1px ヘアライン |
| `--primary` | `#E9B26A` | 灯り。下記 §3 の 4 用途のみ |
| `--text-1/2/3` | `#F5F1EA` / 64% / 38% | 本文 / 補助 / メタ |
| `--scrim-min` | `rgba(0,0,0,.45)` | 写真上スクリムの**下限** |

## 2. 写真の上の文字（必須）
- 写真上のテキスト・アイコンは、**`--scrim-min` 以上**の暗さの膜の上に置く。
- 標準形：`linear-gradient(to top, rgba(0,0,0,.72) 0%, rgba(0,0,0,.45) 34%, transparent 68%)`。
- 名前バッジなど上端に置く要素は、上からも `rgba(0,0,0,.45)` 以上のグラデをかける。
- スクリムは `pointer-events: none`。

## 3. `--primary` を使ってよい場所（これ以外は禁止）
1. 埋まった枠 / 選ばれた状態のインジケータ
2. 絆ゲージの残量
3. 主要 CTA（1 画面に 1 つまで）
4. マッチ通知の灯り

区切り線、見出し、リンク下線、アイコン全般に灯りを使わない。透過は `rgba(233,178,106,α)` で作る（別の色相を混ぜない）。

## 4. スマホ規約
- キャンバス 402×874、画面角丸 55、SafeArea = 上 59（Dynamic Island 含む）/ 下 34。
- タップ範囲 **最小 44×44pt**。アイコンの見た目が 20px でも当たり判定は 44。
- MainView の 3 枠はヘッダ込みで **1 画面に収める**（スクロールで 4 枠目を出さない）。

## 5. 状態の表し方
- **危機・解除接近** = 赤ではなく退色。`filter: grayscale(x) contrast(1.05)` + 粒子オーバーレイ（不透明度 0.06〜0.14）を写真に。x は残り時間比で 0 → 1。
- **クールダウン / 空き枠** = 写真なし・`--surface` の面・破線ヘアライン・`--text-3` の mono ラベル。
- **非活性** = 不透明度ではなく `--text-3` への色替えで表す。

## 6. 禁止事項
- 検索・一覧・ランキング・いいね数の表示（コンセプト違反）。
- 4 枠目以上の同時マッチ表現。
- 2 色目のアクセント、赤・緑のセマンティックカラー。
- 絵文字、手描き SVG イラスト。
- 1 コンポーネントに 3 つ以上の視覚効果（影 + グロー + ぼかし等の重ねがけ）。
