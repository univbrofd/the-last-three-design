# taste.md — the last three / 視覚言語

## 一行で
**暗い部屋に、三つだけ灯りがある。** 写真が主役で、UI は写真を邪魔しない“縁”に徹する。

## 情緒の四本柱
1. **写真が主役** — 画面の面積の 60% 以上を相手の写真が占める。UI 要素は写真の上に浮くのではなく、写真に *沈む*（スクリム越し）。
2. **親密・クローズド** — グリッド一覧・検索・ランキング・フォロワー数など「公開性」を示す表現を一切持たない。常に 1 対 1、最大 3。
3. **選ばれた特別感** — 灯り（`--primary` #E9B26A）は「枠が埋まった」「絆がある」ときにだけ点く。UI の装飾では絶対に使わない。
4. **喪失の緊張感** — 危機は赤ではなく **彩度の喪失** で表す。写真がモノクロに寄り、粒子（ノイズ）が乗り、灯りが細る。

## やること / やらないこと
| | やる | やらない |
|---|---|---|
| 色 | 黒〜炭 + 灯り 1 色 | 2 色目のアクセント、赤いアラート、グラデ背景 |
| 面 | 1px ヘアライン + 面の明度差 | ドロップシャドウ、ネオン、グロー多用 |
| 角 | カード 18 / シート 24 / 端末 55 | 完全な直角、過度なピル化 |
| 動き | 呼吸（4s ease-in-out）、フェード 240ms | バウンス、スライドイン祭り |
| 文字 | 日本語ゴシック + 英数セリフ + メタ mono | 装飾書体、絵文字 |

## モチーフ
- **三つの枠** — 画面のどこかに必ず「3」の可視化がある（●●○ / 3 スロット / 3 本のヘアライン）。
- **灯り** — 提灯のような暖色の点。埋まった枠、生きている絆、送信ボタン。
- **退色** — `filter: grayscale()` + 粒子オーバーレイ。解除が近いほど強まる（0% → 100%）。
- **スクリム** — 写真上の文字は必ず黒 45% 以上の膜の上に。膜は下端から立ち上がるグラデーション。

## エフェクト予算
1 コンポーネントにつき視覚効果は **1〜2 個まで**。例）MainView のカード = スクリム + 角丸のみ。BreakupView の写真 = 退色 + 粒子のみ（そこに影やグローを足さない）。

## コピーの声
- 短い。断定。相手を急かさない。
- 一人称は使わない。ユーザーへの呼びかけは「あなた」を避け、状況だけを書く。
- 例）「AI が探しています」「3 枠のうち 2 枠」「23:41:07 で解除されます」「自分から手放すと 14 日間、待機になります」
- 感嘆符・絵文字なし。マッチ通知だけは例外的に少し高揚してよい：「1 枠が埋まりました」
